# Screenshots

Drop the image files referenced by the main [README.md](../README.md) into this
folder using these exact filenames (PNG recommended):

| File                        | What to capture                          |
| --------------------------- | ---------------------------------------- |
| `login.png`                 | Login page                               |
| `register.png`              | Register / sign-up page                  |
| `dashboard.png`             | Main dashboard with notes list           |
| `editor.png`                | Rich-text note editor                    |
| `ai-features.png`           | AI summarize / generate panel            |
| `profile.png`               | Profile page                             |
| `settings.png`              | Settings page                            |
| `recycle-bin.png`           | Recycle bin page                         |
| `gif/preview.gif`           | Short screen recording of the app in use |

Tips:
- Keep widths around 1280–1600px for crisp rendering on GitHub.
- For the GIF, record a short flow (create note → AI summarize → export) and
  keep it under ~10 MB so it loads quickly.
